## Cómo funciona

GZMNET obtiene la configuración de conexión del panel mediante tu token y la guarda cifrada en el dispositivo. Puedes actualizarla manualmente desde la app o dejar que se renueve según el intervalo definido para tu cuenta. La conexión usa el motor Xray con el túnel VPN de Android para enrutar el tráfico de las demás aplicaciones del teléfono o TV por Wi‑Fi o datos móviles. Android deja fuera del túnel la propia app GZMNET para evitar que las conexiones del núcleo Xray regresen al mismo túnel. La configuración local se conserva si el panel no responde temporalmente.

## Actualización desde la app

Entra en **Ajustes → Actualizaciones → Buscar actualización**. Cuando encuentre una build nueva, toca **Descargar e instalar** y confirma en el instalador de Android. Si Android lo pide, permite a GZMNET instalar apps de esta fuente y vuelve a la app para abrir el instalador otra vez. Las compilaciones de GZM-APP usan una firma estable para que Android acepte las actualizaciones posteriores sin desinstalar la app.

## Diagnóstico

En **Ajustes → Diagnóstico** puedes copiar los errores recientes o compartirlos con el creador desde el menú de compartir de Android. El registro guarda solo errores y demoras de GZMNET, se limita en tamaño y oculta tokens, contraseñas y enlaces de servidores. No se envía nada automáticamente; revisa el informe y confirma tú el envío.
