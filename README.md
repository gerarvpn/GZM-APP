## Cómo funciona

GZMNET obtiene la configuración de conexión del panel mediante tu token y la guarda cifrada en el dispositivo. Puedes actualizarla manualmente desde la app o dejar que se renueve según el intervalo definido para tu cuenta. La conexión usa el motor Xray con el túnel VPN de Android para enrutar el tráfico de las demás aplicaciones del teléfono o TV por Wi‑Fi o datos móviles. Android deja fuera del túnel la propia app GZMNET para evitar que las conexiones del núcleo Xray regresen al mismo túnel. La configuración local se conserva si el panel no responde temporalmente.
