# Privacidad de GZMNET

Para consultar el estado de la cuenta y descargar su configuración, GZMNET se comunica con el panel asociado al token que introduce el cliente. La solicitud incluye el token, un identificador de dispositivo, el nombre del dispositivo y el hash de la configuración guardada. El panel usa esos datos para validar la cuenta, aplicar el límite de dispositivos y entregar la configuración.

El token y la configuración local se guardan en almacenamiento cifrado del dispositivo. El tráfico de Internet se enruta por el servidor configurado por el proveedor; el operador de ese servidor puede procesarlo conforme a sus propios términos y políticas.

Al desactivar la cuenta desde la app, se eliminan el token y los perfiles guardados localmente. Para consultas sobre los datos tratados por el panel, contacta al proveedor que te entregó el token.
